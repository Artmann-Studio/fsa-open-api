# TMF641 Service Ordering Management

**FSA status:** Reference  
**Documentation used:** Reference implementation kit, version 4.2.0  
**Base path:** `/tmf-api/serviceOrdering/v4`

## What Film Site Access uses it for

An order for a service, for example access to a film site for a period. Not in the MVP.

Encyclopedia Galactica has the data entities ServiceOrder (25) and ServiceOrderLine (26), but no information object refers to TMF641 yet.
